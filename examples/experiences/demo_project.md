# 虚构示例：校园预约系统（不代表你的经历）

## 基本信息
本文件仅用于测试检索，所有经历都是虚构的。四人课程项目。
项目使用 Python、Flask、SQLite、HTML 和 Git。

## 我的贡献：后端开发
【虚构测试资料】我负责使用 Python 和 Flask 实现预约创建与取消接口。
我验证请求中的日期和用户信息，并返回明确的错误信息。
结果是交付了可演示的预约接口；没有性能提升数据。
示例证据位置：虚构仓库 app/routes/bookings.py。

## 我的贡献：SQL 与数据库
【虚构测试资料】我负责设计用户、房间和预约三张 SQLite 表。
我编写 SQL JOIN 查询，关联预约记录与房间信息，并用参数化查询处理输入。
结果是能够按用户查询预约明细。
示例证据位置：虚构仓库 schema.sql 和 app/queries.py。
